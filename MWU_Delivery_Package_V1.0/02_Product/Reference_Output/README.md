# Reference outputs

This directory is populated per accepted milestone with client-authorized examples only.

- L1a: one accepted ZIP containing the speaker TextGrid, RTTM/CSV and N muted-mirror WAVs.
- L1b: one Praat draft ZIP containing threshold TextGrids, a pre-review diagnostic workbook and a review note.
- L2: transcript units, linguistic feature tables and unresolved-items report.
- L3: final matrix, workbook, codebook and archive index.

Technical manifests, label tables, transition evidence, flags and hashes remain in the session
archive rather than appearing as separate customer downloads. No participant-level research data
is stored in this generic repository edition.
