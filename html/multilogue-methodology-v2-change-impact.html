01 · EMAIL SUMMARY

Stop

暂停旧 binary 工作

停止 sounding/silent 继续校准，避免工程时间与云资源投入到即将被替换的路径。

Redefine

区分停顿的责任

沉默可能是 own pause、listening、transition 或 shared lapse。只有 op 是核心犹豫指标。

Calibrate

整段跑 Multilogue04

Evaluate

用结果决定扩大采购

若新输出与 interactional metrics 对齐，客户才会认真考虑完整数据集的后续使用。

Gold 边界：客户明确说旧 binary corrections 不是九标签 ground truth。它们最多作为 boundary seed，因此旧的“80%”也不能迁移成新方案的准确率。
客户明确要求我们做

  • 处理完整 Multilogue04，而不是短片段
  • 用九分类和 persistent floor 生成可复核草稿
  • 使用 Tier 6 标低置信区间
  • 说明新的六层 TextGrid 是否适合当前 pipeline
客户明确要求停止

旧 binary multilogue 校准

  • 不要继续把 sounding/silent 当多人研究基线
  • 不要继续用 mirror silence 代表 speaker hesitation
  • 不要把旧修正结果当九分类 gold
  • 不要为细分类训练重型自定义模型

  • 不确定项进入 flags，而不是静默猜测
  • 研究团队继续在 Praat 人工检查
  • 自动结果仍是 draft，不是最终研究数据
商业意图

  • 客户没有直接承诺完整采购
  • 本轮结果用于判断 interactional metrics 是否可行

02 · APPENDIX ANALYSIS

Word 技术附录到底提出了什么

这不是一份参数说明，而是一份新的 multilogue measurement specification。它从数据假设、状态机、标签、输出到验证责任，重新定义了 L1a/L1b。

章节主题核心内容工程影响
§1Scope 与 task boundary

单房间麦克风、16 kHz mono、三人 group exam；一个 recording 可能包含多个 task，floor 在每个 task 开始时重置。

新增输入
§2为何不能当三段 monologue

Listening、own pause、transition 和 lapse 在 mirror 中都表现为静音；hard masking 还会改变阈值统计并制造边界瞬态。

否定旧核心
§3–4九标签与参数表

固定九类标签；P=0.25/0.35，建议 0.20；L=1.0；G=2.0；overlap≥100 ms；10 ms frame；200 s window。

新配置模型
§5Stage 1：shared timeline

Original mix 只做一次 room sounding/silence；叠加可重叠 speaker attribution、confidence、verbatim word timing 与 artifact 分类。

L1a/L1b 重构
§6Stage 2：floor state machine

R1–R5 维护 S1/S2/S3/FREE；pause 不自动释放 floor；silence 需要 lookahead 才能判断 op/tr/shs。

全新模块
§7–8Stage 3：label assignment

speaker state × floor state 查表，再应用 ol 与 x precedence；f/bc 依赖词汇规则，不再只是声学判断。

全新模块
§9Signed FTO

FTO=next onset−previous offset；负值是 overlap。附录同时承认自动边界不足以直接支持精细研究值，必须人工校正。

高风险新增
§10六个 worked examples

覆盖 backchannel across pause、overlap transfer、failed bid、lapse、artifact、missed speech，可直接转为状态机单元测试。

验收资产
§11新输出合同

每 task/threshold 一个 TextGrid：N 个 speaker tiers + floor + transition points + flags；另有 CSV、RTTM 和 method sidecar。

替换交付物
§12–13Validation 与待确认项

研究团队负责 gold、DER、IRR、fairness、sensitivity；我们负责输出可评分 artifact、日志、flags、revision 与配置。

责任边界
附录中最重要的自我约束：它没有声称自动系统会直接给出最终 FTO 真值。它明确要求自动预标注 + Praat 人工边界修正。这一点必须保留在 SOW 和 UI 状态中。

03A · CONCRETE EXAMPLE

同一段“没有声音”，研究含义完全不同

旧 mirror 模型只看某位 speaker 有没有能量。新方法必须同时看 room audio、所有 speaker activity，以及谁持有 floor。

Old binary interpretation

Speaker 不出声 = pause

把他人发言期间的 listening time 也当作该 speaker 的 silent hesitation，系统性放大 breakdown disfluency。

No energy+speaker mirror=silent
Methodology v2.0

Silence + floor history = typed state

同样的无声段，会根据 floor 是否持续、接下来谁说话、时长是否超过 L，分为 op / pf / tr / shs。

04 · TARGET ARCHITECTURE

新方案如何落到我们的工程里

输入音频和 diarization 仍然有用，但 pause taxonomy 的证据源从 per-speaker mirror 改为 shared original timeline。

Current PoC

Mirror-first binary chain

已交付、可监听，但不再是多人暂停测量的有效基线。

1Pyannote diarizationspeaker turns / RTTM / overlap data
2N muted-mirror WAV其他区间硬置零，按 speaker 生成
3Praat per mirror每个镜像独立算 sounding / silent
4invalid override把其他 speaker 时间统一覆盖成 invalid
56 binary TextGrids3 speakers × 0.25 / 0.35 s
Target v2.0

Shared-timeline interaction chain

将声学、speaker attribution 与互动 floor 分开，再组合成研究标签。

1Original mix shared VADroom sounding / silence 只计算一次
2Parallel speaker activity允许 overlap，confidence 与 identity 稳定
3Event + lexical cuesvocalisation / artifact / f / bc
4Persistent floor R1–R5claim / retain / transfer / free with lookahead
5N+3 tier TextGridspeaker labels / floor / FTO / flags
最重要的架构边界

Muted mirrors 继续用于监听、兼容和音节核计数；需要增加 5–10 ms fade。但 op / pf / tr / shs 不再从 mirror 的强度曲线推断。

STAGE 1

共享时间轴与归属层

  • Original 16 kHz mono
  • 10 ms room activity frames
  • Overlap-aware speaker streams
  • Verbatim timed words
  • Vocalisation / laughter / artifact
STAGE 2

Persistent floor 状态机

  • S1 / S2 / S3 / FREE
  • R1–R5 with second pass
  • P = 0.25 / 0.35 / optional 0.20
  • L = 1.0 s, G = 2.0 s
  • Low-confidence propagation
STAGE 3

研究标签与可复核输出

  • N speaker tiers with nine labels
  • Floor interval tier
  • Signed FTO point tier
  • Flags review tier
  • CSV / RTTM / method log / QA
Human review 仍是最终边界

附录自己明确：100–500 ms 级 FTO 不能从未复核 diarization 直接当最终研究值。自动层预标注，研究者在 Praat 修正转移两端边界并报告 correction cost。

05 · LABEL ATLAS

九类标签不是九个名字，而是九种统计责任

过滤查看不同语义族。每个标签同时定义 Praat 中看到什么，以及哪些时间能进入 fluency 指标。

sproduction

Speaking

Floor holder 产生可理解的 lexical speech，包括 laughter-talk。

计入 phonation 与 articulation rate
fproduction

Filled pause

Floor holder 的 uh / um / er、鼻音或延长元音。

计入发声，同时作为 hesitation
bcinteraction

Backchannel

非 floor holder 的支持性短回应，≤3 words 并通过词表测试。

默认不计 listener phonation，不转移 floor
olinteraction

Overlap

至少 100 ms 的同时发言，且不是纯 backchannel。

参与 speaker 均标 ol，仍计入 phonation
opsilence

Own pause

Floor holder 安静后仍保留话轮，随后本人继续。

核心 breakdown-fluency pause
pfsilence

Partner’s floor

他人持有 floor 时，本 speaker 的正常 listening 状态。

绝不进入该 speaker 的 hesitation
trtransition

Turn-transition gap

FREE floor 下不超过 L 的交接空档，写在所有 speaker tier。

归属由 between-turn convention 决定
shsgroup silence

Shared silence

FREE floor 超过 L，或持续到 task 结束的 group lapse。

不自动归责给某位 speaker
xexcluded

Unusable section

无词笑声、咳嗽、敲击、纸张声或背景入侵。

从 rate 分子和分母中移除
