# MWU Layer UI implementation baseline

Open `MWU_Layer_UI_Prototypes.html` to switch between the four approved target Layer workspaces. All
values are illustrative and no client data is included. The screens define the implementation
contract; they do not claim that every control is already available in production.

## Review images

1. `prototypes/01-l1a-speaker-review.png` - candidate listening, researcher decisions and S1-SN mapping.
2. `prototypes/02-l1b-interaction-timing.png` - thresholds, Path B, nine labels, Praat review and grouped artifacts.
3. `prototypes/03-l2-research-analysis.png` - activation inputs, approved modules and the Layer 3 handoff.
4. `prototypes/04-l3-matrix-validation.png` - matrix preview, provenance, exceptions and release gate.
The interaction and requirement mapping are documented in `../ui-design.md`.
